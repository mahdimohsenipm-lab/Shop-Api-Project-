# Shop-Api-ASP.NET

E-commerce API project built with ASP.NET Core and Clean Architecture.

## Features
- User authentication with JWT
- Product management
- Order handling
- Clean Architecture structure
- RESTful API endpoints

## Tech Stack
- ASP.NET Core
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication
- Identity
- **Admin Panel:** Razor Pages
- **Auth Strategy:** Cookie-based (for Panel) & JWT (for API)

## Admin Panel
The admin panel is built with Razor Pages and uses cookie authentication.


## Project Structure
- Common
- Data
- Entities
- Services
- StoreTest
- WebFramework

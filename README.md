# Shop API - ASP.NET Core

An e-commerce REST API built with ASP.NET Core following Clean Architecture principles.

## Architecture

* REST API for client applications (JWT Authentication)
* Admin Panel built with Razor Pages (Cookie Authentication)
* Layered architecture based on Clean Architecture

## Features

* JWT Authentication
* Cookie Authentication
* ASP.NET Core Identity
* Product & Category Management
* Shopping Cart
* Order Management
* Discount Code Management
* ZarinPal Payment Integration
* Global Exception Handling

## Tech Stack

* ASP.NET Core
* C#
* Entity Framework Core
* SQL Server
* ASP.NET Core Identity
* JWT Authentication
* Cookie Authentication
* Razor Pages
* AutoMapper

## Project Structure

```text
├── Common
├── Data
├── Entities
├── Services
├── StoreTest
└── WebFramework
```

## Getting Started

1. Clone the repository.
2. Configure the SQL Server connection string.
3. Apply Entity Framework Core migrations.
4. Run the project.
